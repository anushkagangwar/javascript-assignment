## Capstone Project: Product Inventory Dashboard

A simple interactive dashboard built using HTML, CSS, and JavaScript to manage products and display inventory information.

### Features
- Add products with their names and prices
- Validate product details
- Prevent duplicate product names
- Automatically calculate the total number of products
- Calculate total inventory value
- Categorize products by price
- Filter affordable products priced under $200
- Generate a formatted product report
- Responsive layout for different screen sizes

### Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Add products and explore the dashboard features.
